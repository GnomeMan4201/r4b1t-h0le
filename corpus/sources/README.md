# Pinned corpus source snapshots

Files in this directory are exact, review-pinned source snapshots used to reproduce corpus provenance locally. They are not fetched at runtime and do not automatically become selectable resources.

Each snapshot is paired with a manifest under `corpus/catalogs/` containing the upstream URL, exact revision, source path, and SHA-256 digest. Third-party content remains subject to its upstream license and attribution terms.
