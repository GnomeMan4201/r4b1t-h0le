# Unusual security resources — curated batch v1

116 concrete resources proposed; no runtime promotion or selection weighting. Scope remains cybersecurity and investigation. Old research is retained for technical value; publication age is not a health signal.

Each exact URL is bound to a publisher link-index snapshot and a declared resource type. Editorial rationales are scope decisions, not an independent full-content or safety audit. Destination checks observed HTTP 200 at the recorded time; PDF checks inspected a bounded prefix.

Excluded: two unavailable historical mirrors and shattered.io, whose publisher page contained unrelated gambling material. This illustrates why HTTP 200 alone cannot establish relevance.
